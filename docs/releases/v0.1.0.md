# mojo-mmap v0.1.0

## What it does
Memory-mapped files for Mojo: a whole file as a zero-copy `Span`, read-only or writable, with `madvise` and `msync`.

## Highlights
- `MappedFile`, `create`, five `madvise` hints, `flush`.
- 24.9 GB/s scan through the mapping vs 1.2 GB/s through `read_bytes()` (256 MiB, warm cache).

## Changes
- First release.

## Verified
- 4 scenarios byte-identical with Python `mmap`, each twice; 3/3 mutants caught; `scripts/ci.sh` PASS on Mojo 1.2.0 and 1.3.0.dev2026110305.

## Known limits
- Linux only. No resize, no private copy-on-write mappings, no partial-range mapping.

## Upgrade / run
- Add `mojo-mmap` (conda: `mojo-mmap`), then `from mmap import MappedFile`. Try `examples/quickstart.mojo`.
